A terminal-based UI for git log/show/diff/status (common read-only git commands)

Features

  • Press Enter to open a commit from the log.
  • Keep your muscle memory with familiar pager keys: j/k, /, n, and q.
  • Toggle file stats and expanded patches with s.
  • Get syntax-highlighted diffs with delta, used automatically when installed.
  • Spot agent coauthors with badges: ꩜ Codex and ❋ Claude Code.
  • Lockfiles fold automatically to keep source changes in view; expand them when needed.
  • View image files in diffs in supported terminals (Kitty and Ghostty, cmux and more).
  • Expand submodule diffs to inspect the changes inside.
  • Follow commits and working-tree changes live with glog --watch.

Install

Install, then run glog inside any Git repository.

$ cargo install glog-tui

Requires Git and the latest stable Rust toolchain.
